## 公開方法（GitHub Pagesの例）
1. GitHubで新しい公開用リポジトリを作成する。
2. このZIPを展開し、中のファイル一式をリポジトリの最上位にアップロードする。
3. リポジトリの **Settings → Pages** を開く。
4. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存する。
5. 表示されたURLでサイトを確認する。

※公開設定やアカウント登録はユーザー側で行う必要があります。サービスの年齢条件や利用規約も確認してください。

## 投稿機能についての重要な注意
現在の `admin.html` は管理用の原稿作成補助であり、本物のログイン機能・オンライン投稿機能ではありません。`content.json` を更新して再アップロードすればニュースや事業報告を更新できます。
本格的な管理者ログインとブラウザからの投稿には、サーバー側で認証・権限確認を行う仕組みとデータベースが必要です。パスワードをHTMLやJavaScriptに直接書き込まないでください。
